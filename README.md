# Somar Representações — Android v2

Aplicativo Android para consulta de catálogos da equipe comercial.

## Recursos v2
- Tela de abertura com identidade Somar.
- Interface do catálogo carregada localmente para abrir mais rápido.
- Catálogos, capas e PDFs continuam sendo consultados do Supabase em tempo real.
- Compartilhamento nativo do Android.
- Abertura do WhatsApp em links de compartilhamento.
- Download de PDFs com nome do arquivo quando disponível.
- Compatível com Android 6.0 (API 23) ou superior.

## Build
O workflow em `.github/workflows/build-apk.yml` gera o APK de teste em `assembleDebug`.
